# Дополнительный функционал (предложения)

Помимо трёх основных задач, для закрытия проблем Outlook ↔ Yandex:

| # | Модуль | Проблема | Решение |
|---|--------|----------|---------|
| 4 | **notify_user** | Пользователь не знает, что встреча добавлена | Письмо «встреча от Сбера добавлена в календарь» |
| 5 | **attachment_links** | Нет вложений во встрече через CalDAV | Файлы из TNEF → Яндекс Диск → ссылка в описании |
| 6 | **imap_health** | Почта перестала синхронизироваться (кейс Беловой) | Алерт при ошибке IMAP / нет новых UID N часов |
| 7 | **duplicate_merge** | Дубли после ручного «Создать событие» | Слияние по UID / время+тема |
| 8 | **forward_fix** | Пересылка встречи = пустое письмо (Трунаева) | Парсинг forwarded TNEF в новое событие |
| 9 | **freebusy_report** | Нет занятости коллег (Чуруткин) | Отчёт: кто подключён к общим календарям / org-wide freebusy (если Яндекс отдаст) |
| 10 | **outbound_verify** | Исходящие к банкам не доходят | Проверка: событие создано в web CalDAV + SMTP log + bounce |

Задача **attachment_links** уже заведена в БД как заготовка (по умолчанию выключена).
