## Подготовка (один раз)

1. Docker запущен, сервис поднят:
   ```bash
   cd kalendar_migration/calendar_bridge
   docker compose up -d
   curl http://localhost:8091/health
   ```
2. В админке → **Пользователи** — у тестового ящика статус «активен».
3. Для исходящих: SMTP в `.env` + домены в **Организации**.

## Кейс A — входящее приглашение → встреча в календаре

**Что проверяем:** письмо с `.ics` / winmail / no_name превращается во встречу у получателя.

### Шаги

1. На ящик тестируемого (например `s.churutkin@rubda.ru`) приходит письмо-приглашение.
2. Админка → **Задачи** → `incoming_invites` → **Запустить**.
3. Смотрим **Входящие**:
   - есть письмо;
   - «Подробнее» → параметры встречи (название, время, участники);
   - статус **«Встреча создана»** (не «распознано / DRY RUN»).
4. Просим коллегу открыть **calendar.yandex.ru** и проверить, появилась ли встреча.
5. Опционально: телефон / Outlook (CalDAV) — должна подтянуться **дата/время**, вложений может не быть.

### Как спросить коллегу

> Прислал тестовое приглашение на встречу «ТЕСТ Calendar Bridge …».  
> Загляни в Яндекс Календарь (веб) — появилось ли событие? Во сколько оно?

## Кейс B — исходящее .ics внешнему участнику

**Что проверяем:** встреча в CalDAV с участником из списка организаций → письмо с `.ics`.

### Шаги

1. **Организации** — добавлен домен получателя (например `gmail.com` или домен «банка»).
2. В `.env` заполнены `SMTP_USER` / `SMTP_PASSWORD` / `SMTP_FROM` (пароль приложения «Почта»), сервис перезапущен.
3. В календаре тестового ящика создана встреча с внешним участником на этом домене.
4. **Задачи** → `outgoing_invites` → **Запустить**.
5. **Исходящие** → «Подробнее»: кому, тема, превью `.ics`, статус отправлено.
6. На внешнем ящике открыть письмо и `.ics`.

## Если что-то не так

| Симптом | Что сделать |
|---------|-------------|
| Баннер «запись выключена» | `CREATE_EVENTS_ENABLED=true`, пересоздать api |
| Письма нет во «Входящие» | письмо ещё не дошло / не тот ящик / задача не запускалась |
| «Распознано, не создано» | включить создание событий, **Перечитать из IMAP** |
| Пустые время/участники | **Перечитать из IMAP** (часто winmail богаче inline ICS) |
| Ошибка CalDAV | пароль приложения «Календарь», имя календаря = «Основной» |
